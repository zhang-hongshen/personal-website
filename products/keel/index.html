Command console

Its own connection, blocking commands you can stop, history, completion and formatted results.

Memory analysis

Server info

Memory, clients, hit rate and keyspace at a glance, plus config and the slow log.

Safety

Careful by default

Confirm first

Deletes, FLUSHDB and other dangerous commands always ask first.

Preview, then delete

Delete by pattern shows the matching keys first, then UNLINKs them in batches.

Transactional edits

Changes to a value are applied in a transaction.

Large values handled
