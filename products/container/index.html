Containers, made simple

Pull an image, create a container and start it — all in a native Mac app that launches in seconds.

Images

Pull, list, search and delete images from any registry.

Containers

Create, start, stop, inspect and delete — with CPU and memory limits for each.

Published ports

Ports the image exposes are filled in for you, and listen only on 127.0.0.1.

Host folders

Mount folders from your Mac, read-only if you like. Declared volumes come prefilled.

Networks

Join containers to one or more networks so they can reach each other.

Isolated by design

Each container stays apart from your Mac and from the others.

Setup

Everything in one form

  • Ports — choose host ports, or leave them unpublished.
  • Folders — pick a folder from your Mac, read-only if you like.
  • Resources — set CPU cores and memory for each container.
